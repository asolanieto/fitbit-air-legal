Política de privacidad — fitbit-air

Última actualización: 21 de noviembre de 2026.

Qué datos se usan

fitbit-air lee, con el permiso que el propio usuario concede en Google, los datos de su cuenta de Google Health: actividad, pasos, sueño y frecuencia cardíaca.

Dónde se guardan

Los datos se guardan únicamente en un servidor doméstico privado, bajo el control del propietario de la aplicación. No se envían a terceros, no se venden y no se usan para publicidad.

Para qué se usan

Solo para mostrar al propio usuario sus datos en un panel personal.

Cuánto tiempo se guardan

Se conservan mientras el usuario mantenga la aplicación. El usuario puede revocar el acceso en su cuenta de Google en cualquier momento, y los datos locales pueden borrarse a petición.

Uso de datos de Google

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios API de Google, incluidos los requisitos de uso limitado.
